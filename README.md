# Messendjer UI Concept

Статичный UI/UX-концепт мессенджера в визуальной логике современных сервисов Яндекса: светлая поверхность, крупные радиусы, контрастный чёрный текст, жёлтые акценты и красная главная кнопка действия.

## Как посмотреть

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 4173
```

После запуска интерфейс будет доступен по адресу `http://127.0.0.1:4173`.
